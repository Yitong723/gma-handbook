- **✏️ 编辑文字** —— 点开后可直接改页面上的任意文字，改动自动存在访问者自己的浏览器里（不影响别人看到的版本），可用「⬇️ 导出 HTML」把改好的版本存成文件。
- **⤓ 保存 / 打印 PDF** —— 浏览器打印对话框里选「另存为 PDF」，记得勾选「背景图形」，纸张 A4 纵向。
